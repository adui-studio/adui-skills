# Contributing

## Third-party Skill

To add a third-party skill:

1. Add it to `registry/skills.json`.
2. Add the skill ID to the appropriate profile.
3. Document why the skill is useful.
4. Review its current `SKILL.md`.
5. Review security-sensitive instructions.

## ADui Skill

ADui-maintained skills belong under `skills/`.

Each skill must include:

- `SKILL.md`
- `agents/openai.yaml`

Keep skill instructions focused and concise.
