# ADui Coding Task Output Contract

Use this English fallback order:

1. Requirements and constraints.
2. Assumptions and risks.
3. Solution and code.
4. Changed locations and reasons.
5. Run/test/verification results, clearly distinguishing executed vs. not executed.
6. Unresolved questions.
7. Optional Git recommendation when useful.

Do not claim commands, tests, builds, or runtime checks were executed when they were not. Do not perform commit/push/merge/release unless explicitly requested.
