# ADui Skills Pack v0.2.0 Public Preview
> Pre-release validation found that the historical `gh-cli` Skill was removed from the current `github/awesome-copilot` main branch. This release no longer installs or tracks that unavailable upstream by default.


> Before release, the Registry was synchronized with the current Flutter official skills tree so removed legacy skills cannot block the Folder Hash lock.
This is the first public preview of ADui Skills Pack: a reviewable, composable and maintainable distribution for AI Coding / Agent Skills rather than a vendored copy of third-party Skill source.

Highlights include seven ADui-maintained core Skills, an 84-entry external Registry with Folder Hash tracking, 29 composable Profiles, npm/pnpm/Yarn/Bun-aware Profile installation, weekly human-reviewed upstream update PRs, GitHub-to-CNB mirroring, and Chinese-first documentation with English fallbacks.

`v0.2.x` is a preview line. Registry/Profile schema and CLI details may still evolve before `v1.0.0`. The `database-schema-design` upstream remains disabled, and the skills.sh Pack must be created manually after Vercel sign-in.
