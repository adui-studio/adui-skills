# ADui Skills Pack v0.2.0 Public Preview
> 发布前校验发现 `github/awesome-copilot` 当前主分支已移除历史 `gh-cli` Skill；本版本不再默认安装或跟踪该失效上游。


> 发布前 Registry 已同步 Flutter 官方当前 Skill 目录，避免已移除的历史 Skill 阻塞 Folder Hash Lock。
> English fallback: https://github.com/adui-studio/adui-skills/blob/v0.2.0/releases/v0.2.0.en.md

这是 ADui Skills Pack 的首个公开预览版本。目标不是把所有第三方 Skill 复制到一个仓库，而是提供一套可审核、可组合、可更新的 AI Coding / Agent Skills 发行体系。

## 亮点

- 7 个 ADui 自研核心 Skills：Stack Router、功能开发、Vite+、NestJS + Prisma、3D 架构、WebGL2、Tauri v2。
- 84 条第三方 Skill Registry，其中 82 条启用并参与 Folder Hash 跟踪。
- 29 个可继承 Profile，按技术栈组合 Vue、React、数据库、Flutter、Tauri、uni-app、微信小程序、Three.js、Babylon.js、CesiumJS、WebGL2、WebGPU 等能力。
- Profile 一键安装器支持 npm / pnpm / Yarn / Bun，并支持目标项目自动识别、Monorepo 和显式 Agent 选择。
- Git tree SHA / `skillFolderHash` 上游跟踪，路径移动可自动修复，单个上游异常不会拖垮整次检查。
- 每周自动检查第三方 Skill 更新，只开 PR，不自动合并。
- GitHub → CNB 国内镜像同步。
- 中文文档、Workflow、CLI 和维护报告为默认，英文 `.en.md` 兜底。

## 快速开始

```bash
npx skills add https://github.com/adui-studio/adui-skills --skill adui-stack-router
npx skills add https://github.com/adui-studio/adui-skills --skill adui-feature-dev
```

仓库维护者可使用：

```bash
npm run validate
npm test
npm run profile:list
npm run profile:auto-install -- <project-root> --agent codex --dry-run
```

## Public Preview 说明

`v0.2.x` 仍属于公开预览期。Registry/Profile Schema、CLI 参数与安装体验在 `v1.0.0` 前可能继续调整，但会优先保持已公开命令的兼容性。

## 已知限制

- `database-schema-design` 因上游不可稳定访问而保持停用。
- skills.sh Pack 需要登录 Vercel 后在网页创建，因此不随 GitHub Release 自动生成。
- Profile 实际安装依赖 `skills` CLI；建议先使用 `--dry-run` 查看计划。
- GitHub Actions 创建 Weekly PR 的能力可能受 Organization / Enterprise Policy 限制。
