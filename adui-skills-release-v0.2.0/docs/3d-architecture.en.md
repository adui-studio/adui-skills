# ADui 3D / GPU Architecture

English fallback for the Chinese source of truth.

Use `adui-3d-architecture` for technology selection and cross-engine boundaries. Prefer Three.js for flexible general Web 3D, Babylon.js for a fuller real-time engine, CesiumJS for geospatial/globe/3D Tiles, WebGL2 for raw raster control, and WebGPU for modern GPU pipelines or compute. Define coordinate ownership, camera ownership, resource lifecycle, asset pipeline, performance budgets, and fallback behavior before implementation.
