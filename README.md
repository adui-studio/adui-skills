## Architecture

The repository contains:

- `skills/` — ADui-maintained skills
- `registry/` — curated third-party skill registry
- `profiles/` — reusable technology profiles
- `scripts/` — maintenance automation
- `docs/` — architecture and contribution documentation

Third-party skills are referenced from their upstream repositories rather than copied into this repository.
